# Girls-Frontline Pixel Dungeon — Español 🇪🇸

**Traducción al español de Girls-Frontline Pixel Dungeon.**

Este repositorio es una adaptación al español del proyecto **Girls-Frontline Pixel Dungeon**, desarrollado originalmente por **Sharku** y con arte y gráficos de **Namsek**.

Mi aporte a este proyecto consiste principalmente en la **traducción del contenido del juego al español**, con el objetivo de hacer que este proyecto pueda ser disfrutado por jugadores de habla hispana.

> ⚠️ **Importante:** Este proyecto no es un desarrollo original mío. Es una modificación/traducción de un proyecto existente. Todo el crédito correspondiente a los autores originales y a los proyectos de los que deriva se mantiene aquí.

---

## 🎮 Sobre el juego

**Girls-Frontline Pixel Dungeon** es un juego derivado de **Pixel Dungeon** y **Shattered Pixel Dungeon**, ambientado en el universo de **Girls' Frontline**.

El proyecto original fue desarrollado como una obra derivada y sin intención comercial, utilizando como base el código de proyectos anteriores de Pixel Dungeon.

Esta versión tiene como objetivo proporcionar una **traducción al español** de los textos y contenidos del juego.

---

## 🌎 ¿Qué cambia en esta versión?

La principal modificación realizada en este repositorio es:

- 🇪🇸 Traducción del contenido del juego al español.
- 🔤 Adaptación de textos originalmente disponibles en coreano.
- 📝 Traducción de diálogos, objetos, descripciones y demás textos disponibles.
- 📱 Preparación del proyecto para poder compilar una versión Android en español.

El objetivo es mantener el funcionamiento y contenido del proyecto original, modificando principalmente el idioma para hacerlo accesible a jugadores hispanohablantes.

## 🔧 Compilación

El proyecto utiliza **Gradle** para su compilación.

Para generar una versión de desarrollo (`debug`) del APK:

```bash
./gradlew assembleDebug
```

En Windows:

```powershell
.\gradlew assembleDebug
```

El APK generado normalmente se encontrará en:

```text
core/build/outputs/apk/
```

o en la ruta de salida correspondiente configurada por Gradle.
